DHANASHREE — THE AFTERTHOUGHT (VERSION 7)

A cinematic portrait and poetry website with scroll-led portrait scenes, animated typography, a procedural 3D/particle atmosphere, soundtrack controls, and an original Hindi couplet.

OPENING THE SITE
1. Extract this ZIP folder.
2. Open index.html in a modern browser such as Chrome.
3. An internet connection is required for external animation libraries and web fonts.
4. Use “Personalise the media” to preview photographs, videos, and a soundtrack locally.
5. Use “Package my website” to download a ZIP containing selected media and a personalised copy of the site.

COPY / TONE
The copy has been rewritten in a restrained, direct, literary tone. It says plainly that the creator saw Dhanashree in photographs, found her beautiful, and has not met or spoken with her. One original Hindi couplet appears in the central interlude. Replace [your name] in the final letter before sharing.

MEDIA AND PRIVACY
Selected personal media is previewed locally in the browser. It is included only if you explicitly package it. Do not publish another person's photos or videos in a romantic site without appropriate permission.

MOTION
The site includes a Motion toggle and respects the operating system's reduced-motion preference. Test desktop and mobile before sharing. The real-time procedural graphics are stylized effects, not a photorealistic CGI rose render.

This bundle does not host or upload the website online.
